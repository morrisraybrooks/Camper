# user-low-vision

> The user doesn't see well - dashboards/UI need big pictures and big text, picture references for items

The user said (2026-10-17): "i dont see so well so picture references for the items would help a lot."

**How to apply:**
- When building or changing dashboard cards, default to big pictures with large text (16 px or more, names that wrap rather than truncate) and strong contrast.
- Use picture references, such as product photos or 3D emoji, rather than text-only dropdowns or small icons.
- Check screenshots for cut-off labels.

See [[project-camper-shopping]] for the pattern used: button-card templates `shop_pick`/`shop_quick`.
