# project-vehicle-obd

> ELM327 mini Bluetooth OBD-II adapter → Torque Pro (Morris's Android) → HA torque platform; vehicle not yet named

2026-10-17: the user has an **ELM327 mini (Bluetooth)** OBD-II adapter and wants both trouble codes and live data.
- The ODROID has no Bluetooth. A travel trailer has no OBD port, so this is for the tow/daily vehicle. Vehicle: **2016 Toyota Sequoia** (5.7 V8), which tows the camper.
- HA: `sensor: - platform: torque` with `email: vehicle@camper.local`, `name: Sequoia` in configuration.yaml (HA was restarted; `/api/torque` answers). Sensors appear as `sensor.sequoia_*` only after Torque uploads. Backup `configuration.yaml.bak-preclaude-torque-*`.
- Phone side (the user does it): pair "OBDII" (PIN 1234/0000), Torque Pro, Data Logging & Upload → webserver URL `http://100.x.x.x (Tailscale IP):8123/api/torque` (Tailscale) or `http://192.168.0.168:8123/api/torque` at the camper; user email `vehicle@camper.local`; HTTP header `Authorization: Bearer <long-lived token the user creates>`.
- **Built 2026-10-17 (before any real data):** `custom_templates/sequoia.jinja` (seq_entity/seq_value/seq_ok) finds Torque readings by name (regex, tried in order) and converts km/h→mph and °C→°F.
  - Template sensors: `sensor.sequoia_gauge_speed`, `_rpm`, `_coolant_temp`, `_transmission_temp`, `_fuel_level`, `_battery_voltage` (unavailable until Torque uploads), plus `sensor.sequoia_last_update`.
  - Dashboard: `/lovelace-camper/sequoia` with 6 big gauges (2 columns, color segments), a status header (Live/Parked/No readings) and a towing temps tip. The `&b_sequoia` badge sits after Shopping on every view.
  - Tested with fake states (deleted afterwards). Alert `automation.sequoia_transmission_too_hot`: >230°F for 30 s → TTS on Morris's phone (alarm stream) + urgent notify both; >245°F for 15 s → "pull over". Not live-tested (no real data yet).
  - Trouble codes are read and cleared in the Torque app (Fault Codes).
- Trans temp custom PID (unverified for the 2016 Sequoia): PID 2182, header 7E1, equation ((((A*256)+B)*(84/1000))-480)/12 (°C); alternative ((((A*256)+B)*7/100)-400)/10 with a blank header. Sanity check: near coolant temp after a warm drive.
- **Own "Torque clone" (2026-10-17, user: "clone the protocols that torque uses and set it up for me"):**
  - An ESP32 OBD box replaces the phone app. Firmware is in `/homeassistant/esphome/sequoia_obd_fw/` (PlatformIO, ELMduino; build inside the ESPHome container with `pio run`; `make_secrets.py` writes `src/secrets.h` from esphome/secrets.yaml wifi + `.sequoia_cloudhook_url`).
  - It needs a **classic ESP32 (WROOM-32 DevKit)** for BT Classic; it can't be a C3/S3. BT connects to "OBDII" (PIN 1234). Buzzer on GPIO25.
  - It reads mode 01 PIDs 0D/0C/05/2F/42 plus Toyota trans 7E1 2182 and POSTs JSON {speed mph, rpm, coolant °F, trans °F, fuel, volts, trans_raw} every ~5 s to an HA Cloud webhook (id in `/homeassistant/esphome/.sequoia_webhook_id`, cloudhook URL in `.sequoia_cloudhook_url`, both 600). It posts {} when the truck goes off.
  - HA: trigger-based webhook template sensors named like Torque (`sensor.sequoia_speed_obd`, `_engine_rpm`, `_engine_coolant_temperature`, `_trans_temp`, `_fuel_level`, `_voltage_control_module`, `_trans_raw`, and `sequoia_last_update` stamped on upload), so the gauges and the alert work unchanged. Tested end-to-end via the cloudhook, then cleared.
  - Wi-Fi in the truck: Morris's phone hotspot set to the SAME name/password as the camper Wi-Fi (the user types it on the phone).
  - Build: inside the ESPHome container, run `PLATFORMIO_GLOBALLIB_DIR=/tmp/seq_globallib pio run`; ESPHome's global libs (RPAsyncTCP) otherwise break it. Compiled OK (RAM 18%, flash 53%). The flashable bins and FLASH.txt are in ODROID `~/sequoia_obd/`; firmware.bin has the Wi-Fi password and hook URL baked in, so it's chmod 600. esptool isn't installed on the ODROID yet.
  - NOT done yet: the hardware. The user needs a spare classic ESP32 DevKit (the wall panel one is in use), a USB power source in the truck, an optional active buzzer, and the phone hotspot set to the camper Wi-Fi name/password.
