# feedback-no-hvac-tests-without-asking

> Never change the real camper thermostat (setpoints/modes) to run a test without asking first

Never change the real camper thermostat's setpoints or mode just to run a test, unless the user agrees first.

**Why:** On 2026-10-12 Claude raised the Auto heat setpoint to 76 twice (inside was 74°F) to make the furnace run so it could read the furnace cycle code. The user had to fix it at the wall panel and said "your trying to burn me up". Someone (and Daisy the dog) is living in the camper.
**How to apply:** For anything that needs a live heat or cool cycle, ask first, say how long it will run, or wait for a natural cycle. Related: [[project_camper_easytouch]], [[feedback_no_live_preview_flips]].
